# FitFlow Redesign

FitFlow is a redesigned fitness application that provides personalized
workout plans, nutrition tracking, progress monitoring, social features,
real-time notifications and AI-based recommendations.

## Technology Stack

### Frontend
React Native

### Backend
Node.js / NestJS

### Database
PostgreSQL

### Authentication
Firebase Authentication

### AI Service
Python / FastAPI

## Main Features

- Personalized workout plans
- Nutrition tracking
- Progress tracking
- Social sharing and community features
- Real-time notifications
- AI-based recommendations

## Project Structure

- frontend/ - React Native frontend application
- backend/ - Node.js / NestJS backend API
- ai-service/ - Python / FastAPI AI services
- docs/ - Project documentation
